Citation COVERAGE, not correctness. verify_citations.py checks that every `A p.N` in the
data points at a page that really says what the node claims. This checks whether a node
carries a citation AT ALL, and how much of its own declared page range those citations
speak for. A node with no citation is invisible to the checker and its silence is scored
as a clean run -- that is what this exists to surface. See the header for the L-13-3-1 case.

270 nodes parsed from 62 data files; 60 are book=lehninger and carry `A p.N` citations by
convention. The Czech layer does not cite A pages and is not scored here.

==============================================================================
SINGLE-PAGE CITATIONS OUTSIDE THE NODE'S OWN `pages:` RANGE
==============================================================================
A single-page citation is a content anchor: it claims something sits on that page. One
landing outside the node's declared range means either the anchor or `pages:` is wrong.
Two kinds are excluded, both because flagging them would report correct data as suspect:
  - RANGE citations (`A pp.675-686`) -- that is how a node points at a neighbouring section
  - citations inside `coverageNote` -- that is where a node ARGUES its range, which often
    means citing the page it is ruling out (L-25-1-1 on p.914, L-13-3-1's header on p.478)
See the comment above this section for what counting them cost the first version.
  none. Every content anchor in every node sits inside the range that node claims.

For context only -- pages cited in `coverageNote` from outside the range, i.e. a node
showing its work on where the section really starts or stops:
    L-25-1-1       leh_ch25.js      declares 915-930, cites [914] while arguing the range

For context only -- range citations pointing outside the declared range. These are
cross-references to neighbouring sections and are expected:
    L-11-3-1       leh_ch11.js      -> pp.404-407
    L-19-1-1       leh_ch19.js      -> pp.675-686
    L-3-4-1        leh_ch3.js       -> pp.96-100
    L-8-3-1        leh_ch8.js       -> pp.294-296
