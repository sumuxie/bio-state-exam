## Enzyme lectures (added from lecture 2, 酶通论)

**煤 / 媒 → 酶 is the single most frequent error once enzymes are the subject.**
The checklist above only had 霉动力学; the bare character is far more common.
- 煤 / 媒 → 酶 ；主媒 → 主酶 ；和煤 / 荷梅 / 荷美 → 核酶 ；腐霉 → 辅酶
- **没 → 酶**. Same pinyin (méi), so it hides inside sentences that read as perfectly
  grammatical: 那么没有什么特点 is 那么酶有什么特点. Only the biochemistry gives it away.
- coenzyme / cofactor come back transliterated or split: 扣恩赞 / 恩赞 / 扣factor /
  "call enzyme" / "call factor" → 辅酶 / 辅因子
- 米施方程 / 米士方程 / 米十方程 / 米什旺城 → 米氏方程 ；双倒数作图 Lineweaver-Burk ；周转数 kcat
- 煤火 → 酶活 ；唐甘梅 → 糖苷酶 ；底雾 / 底涡 → 底物

### Narrating a derivation

A whole cluster appears whenever the teacher works through an equation aloud. These
are ordinary words displacing the mathematical ones, so the sentence reads fine and
only the algebra reveals the error.

- 另 → 令 ("我们**令** k1 等于…") ；狮子 / 柿子 → 式子 ；推倒 / 推到 → 推导
- 讲设 → 假设 ；位置数 → 未知数 ；反应室 → 反应式 ；设计 → 涉及
- 油粒 / 有利 → 游离 (free enzyme / free substrate)
- 符合物 / 符合体 → 复合物 / 复合体 — constant for the ES complex, not only in structure
- 没活 / 煤火 → 酶活
- symbols: `DDT` → `d[ES]/dt` ；`es b gt` → `es 比 dt` ；`ke` → `k1` ；屁 → P ；
  project → product ；没加按 → 酶加P
- 酶促 is mangled two ways: 酶醋 / 霉粗 → 酶促 ；出速度 → 初速度
- **移植 / 移植剂 → 抑制 / 抑制剂**. More persistent than the 意志 variant, and it takes
  over completely through the passage naming the inhibitor types — the one stretch
  where the word matters most.
- Lineweaver-Burk cluster: 节率 → 斜率 ；节距 / 结局 → 截距 ；焦点 → 交点 ；除于 → 除以
- 平方反应 → 乒乓反应 ；三速段 → 三羧酸 ；底部 / 底屋 → 底物 (beyond 底雾 / 底涡)
- **美 → 酶** — another true homophone, alongside 煤 / 媒 / 霉 / 没
- 米士 / 米十 / 米生 / 米什 / 米食网中 / 米石 / 米式 / 米施方针 / **米士邦城** → 米氏方程 ；
  米是常数 → 米氏常数
- **每次反应 → 酶促反应** — a true homophone (méi cì / méi cù), reads as ordinary Chinese
- DU → 底物 (joins DOS / 底雾 / 底涡 / 底屋 / 底污)
- 黴 (traditional form) → 酶, in short stretches where the output switches script
- **E and 一 / 1 are confused in BOTH directions**, and only the algebra tells them
  apart: `ES 生成 1加P` is E+P, while the inhibition factor `(1+[I]/Ki)` came out as
  `E加上面I`. Check every isolated E or 1 in an equation against what the step means.
- 静动性 → 竞争性 ；反行征 / 反精神性 → 反竞争性 ；非竞争证 → 非竞争性
- 石子 / 叶子 → 式子 ；鞋率 → 斜率 ；x手 → x轴 ；分子分布 → 分子分母 ；
  一圆一丝方程 → 一元一次方程
- 体物 → 底物 ；没错反应 → 酶促反应 (another true-homophone 没) ；放光氧酸 → 半胱氨酸
- 一支G / 一只鸡 → 抑制剂 (the family is past ten spellings; read for the sense)
- **别够 / 别垢 / 别过 → 别构** ；酶源 → 酶原 (zymogen) ；供价 → 共价 ；枚 → 酶
- 奇变 → 齐变 ；续变 → 序变 (concerted / sequential allosteric models)
- 极廉 → 级联 ；肝宫 → 肝功 ；通宫酶 → 同工酶 ；易促 → 异促 ；妇媒 → 辅酶 ；
  负效用户 → 负效应物 ；刺激件 → 次级键 ；S进取现在 → S型曲线 ；钙油酸 → 甘油酸 ；
  糖胶结合酸素酸 → 糖酵解和三羧酸 ；天多氨酸转甲显胺酶 → 天冬氨酸转氨甲酰酶 ATCase
- 极竞 / 挤进去 → 极性 ；氢水 → 亲水 ；六远环 / 六圆环 → 六元环 ；
  **米作策略 → 咪唑侧链** ；刮基 → 胍基 ；半乙式 → 半椅式 ；糖干腱 → 糖苷键 ；
  极丁质 → 几丁质 ；格兰氏 → 革兰氏 ；左氨酸 → 组氨酸 ；虚同进化 → 趋同进化 ；
  **卖为 → 蛋白酶** ；一蛋白酶 → 胰蛋白酶 ；胰磷乳 → 胰凝乳

  K-STEDING → histidine ；aspirin / sportic → aspartic ；crap cycle → Krebs cycle

  一支剂 / 一支机 / 一致剂 / 一之击. Read for the inhibitor sense, not for a spelling.

- 双导数 → 双倒数 ；氢合力 / 亲合力 / 清和力 → 亲和力 ；成 / 成绩 → 乘 / 乘积
- 米氏方针 / 米释方针 → 米氏方程 ；太渐 / 太健 → 肽键 ；犯直觉 → 反直觉
- 此机应备 / 死机 / 死经位 → 死记硬背 ；吹死 / trace → TRIS ；丸听链 → 烷烃链
- 促灭 / 触灭 → 猝灭 (quenching) ；比顺敏 → 比色皿 ；索钥学说 → 锁钥学说
- 合酶 → 核酶 (another variant) ；积酶 → 激酶 ；四魔虫 → 四膜虫
- 微升 heard as 位 or 微生: 几十位几百位 → 几十微几百微 ；U酶微生 → 每微升
