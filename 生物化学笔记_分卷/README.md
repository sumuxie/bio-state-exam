## 页码怎么标的

部分页面的笔迹一直写到右下角（例如第 5 页的「差向异构体」），所以页码**没有**
直接盖在页面上，而是在每页下方新增一条约 24pt 的白色页脚条，页码写在页脚条右侧。
这样 230 页里没有任何一笔笔记被遮住，代价是页面高度增加约 3%。

页码用的是**整本书的连续编号 1–230**，切分后依然保留原始页号 —— 所以
`生物化学笔记_04_p046-060.pdf` 的第一页显示的是 `46` 而不是 `1`，方便交叉引用。
PDF 的页面标签（page labels）也一并设置了，阅读器的页码输入框里显示的同样是原书页号。
