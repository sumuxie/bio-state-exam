Notebook 笔记本

Saved only in this browser. There is no account and no server behind this — clearing browser data, switching devices, or a private window loses these for good. Every other thing this app remembers (progress, flashcard boxes, the wrong-answer book) can rebuild itself from use; a note cannot. Export downloads one plain-Markdown file with every chapter's note, readable with no app at all — keep it somewhere safe. Import reads it back and merges: a chapter that already has a note gets the imported text appended below a dated rule, never overwritten. 笔记只存在这一个浏览器里——没有账号也没有服务器，清浏览器数据、换设备、或用隐私窗口都会把它们永久丢掉。这个 app 记的其他东西（学习进度、抽认卡分箱、错题本）都能从使用中重新生成，笔记不能。导出会把每一章的笔记打包成一个纯 Markdown 文件下载下来，不装这个 app 也能打开，请保存好。导入读回来是合并：某一章已经有笔记的话，导入的内容会追加在一条带日期的分隔线下面，绝不会覆盖。
