## 加新文件的规矩

**可以加新 md，但要满足三条**（2026-09-12 Ruojin 定）：

1. **它有独立的变化频率。** 跟已有某份变化频率一样的东西，**并进那一份，不新开文件**。
2. **加完当场登记进上面那张表**，写清「多久变一次」和「什么时候读」。
3. **加完跑 `python tools/doc_hygiene.py`**，确认没有跨文件重复、没有断链、开窗口成本没超预算。

**不要新开目录。** 现在的六个目录（`app/` `book/` `content/` `tools/` `_archive/` 和顶层）
够用了。新分支的代价不是硬盘，是**下一个窗口要多花力气才能找到东西**。

**每一圈结束时问一句：这一圈是让文档更简了，还是更重了？**
更重就砍，不要留着「以后可能有用」。
