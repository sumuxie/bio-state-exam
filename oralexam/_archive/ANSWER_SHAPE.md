# 答题形状 — 先审这个，审完才批量写

> 建立于 2026-09-11 · oralexam · 只在此目录产出

每道题写成同一个形状。**主干四格是要背出口的**，储备四格是挡追问的，不背，眼熟即可。

---

## 主干四格（开口 60–90 秒，逐字稿）

| 格 | 说什么 | 为什么这一格必须有 |
|---|---|---|
| **① 定义** | 一句话：**它是哪一类东西 + 由什么界定**。 | 老师默认技术名词你知道，所以他要听的不是名词，是你能不能给出边界。跳过定义直接说内容，等于告诉他你只是背过。 |
| **② 归类与分层** | 它属于哪一类、这类怎么再分、**分类的依据是什么**。依据比名字重要。 | 断层就在这一级：教材默认你有了，从第二级起步。先说"蛋白质结构分四级，因为固定每一级的作用力不同"，再说四级分别是什么。 |
| **③ 机制** | 怎么发生、怎么成立、谁作用在谁身上。 | 这是老师认为的"正常答案"，但它必须排在 ①② 之后，不能打头。 |
| **④ 为什么（三层，到地基就停）** | 连问三次为什么，落到四块地基之一就明说"再往下就不是生化了"。 | 老师的为什么是无限的，你需要一个**能体面停住**的落点，而不是被问到崩。 |

### why 的四块地基（停止规则）

往下追到这四个之一，就停，并且**把这件事说出来**：

1. **热力学** — ΔG、熵、疏水效应。"再往下是物理化学，不是生化了。"
2. **动力学 / 速率** — 速率常数、扩散极限、活化能。"到这一层它是速率问题。"
3. **进化 / 选择** — "因为这么做的活下来了，没有更深的目的。"
4. **测量方法的限制** — "这个定义是被测量方式定下来的，不是被自然定下来的。"（Kd、Km 都是这一类）

说法示例：
> "Ultimately this comes down to the hydrophobic effect, which is an entropy term of water —
> below that it is physical chemistry rather than biochemistry."

这句话本身就是 researcher 的标志：你知道自己学科的边界在哪。

## 储备四格（不背，挡追问）

| 格 | 说什么 | 对应老师的哪种问法 |
|---|---|---|
| **⑤ 怎么发现的** | 哪个实验、谁、大概哪个年代。 | "大家到底是怎么发现该用 plasmid 纯化蛋白的？"——这一格专门挡这种问题。 |
| **⑥ 硬事实** | 具体数字、反应名、酶名、捷克术语 + **Biochemie.pdf 页码**。 | "把葡萄糖变成半乳糖的反应叫什么？"——very specific 题的弹药库。一律从书里挖。 |
| **⑦ 陷阱** | 最容易被抓的混淆。 | 老师追问常常就是在这些点上设的。例：Kd ≠ Km、epimerizace ≠ isomerizace、二级结构靠主链氢键不是侧链。 |
| **⑧ 桥** | 两个能把话引到你熟的地方的接口。 | 你答完主干后主动伸出去，老师顺着你走，就不会自己去挑深坑。你的强项：yeast display、RBD、Kd 的实际测定、定向进化。 |

## 三条写作规矩

1. **① 不许用被定义的词定义自己。**"protein structure 就是蛋白质的结构"作废。
   合格：*"the spatial arrangement of the atoms of one polypeptide chain, described at several
   levels because the forces that fix each level are different."*
2. **⑥ 一律从 OCR 出来的书页里挖，带 PDF 页码。**挖不到就标 `⚠ 未在书中找到`，
   不蒙。（旧项目这条规矩已经抓出过一次错误。）
3. **④ 必须真的停。**写满三层就收，并写明落在哪块地基。三层写不满的题，
   说明这题的深度不在 why 上，改写 ⑤ 或 ⑥。
