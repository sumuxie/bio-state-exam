# 造一张卡的配方

1. **定题**：从 `app/data/_index.js` 挑。优先级：**实测答不上 > w3 > 她说没学过 > w2 > w1**。
2. **挖书**：`grep` `book/pages/p*.txt`。先找**节标题**，那通常就是老师的问法。
   记下每条的 p 页码。**关键数字回 300 dpi 原图核一眼**（`tools/` 里有渲染脚本的样子）。
3. **找书自己的矛盾和限定词**：书说 *"prakticky pouze"*、*"převážně"* 的地方，跟着加限定词。
   两处数字打架的地方，就是 ⑦ 陷阱里最值钱的一条。
4. **写四段**，每段一屏。段 4 必须落在她的主场（yeast display / Kd / directed evolution / RBD）。
   - **代谢类的题另加一格「账」**：投入 / 产出 / **总结（净账）** 三行，缺一不可。
     只给产出是半张账，他一句「那消耗了什么」就能把你问停。见 `DRILL.md` 的通用开口模板。
5. **扫承重名词**：把四段读一遍，对每个名词问一句——
   **「他要是不懂这个词，这句话的结论还成立吗？」**
   - **不成立 = 承重** → **在同一句里加一个从句交代掉**，不能只放定义链。
   - 成立 → 放进定义链备查即可。
   判据和六个实例见 `LOGIC.md` §4b。**越核心的词越容易漏**——
   写的时候会觉得「这还用解释吗」，那正是要检查的地方。
6. **写定义链**：剩下那些不承重但可能被单独问的词，每个一句。
   - **每条定义过四问**：① 说的是它**是什么**，还是判据或后果？（「序列上离得远」是判据，「整条链的折叠」才是三级）
     ② 书哪页说的？加的词有出处吗？书别处有反例吗（grep 全书）？③ 承重名词交代了没？④ 书和 Lehninger 不同时，卡上明说。
7. **写 why 三层**，明确落在四块地基的哪一块，写停止句。
8. **写追问**：从「卡上给了结论没给理由的地方」找，那是他插刀的位置。
   - **另外扫一遍逐字稿里的程度副词**（远、近、大量、很快、大多数）。每一个都要预备
     一条「他要数字怎么办」——给判据 ＋ 给反例，**不要编数**。见 `LOGIC.md` §11。
   每条标危险度（实测 / 高 / 中）。**引号里是八分答案，中文是第二层。**
9. **写「同一个答案，不同问法」**：
   - **第一行永远是这道题的最短问法**（卷面 "What are two critical PTMs for surface and
     secreted proteins?" → 口试 "What is post-translational modification?"）。
     它的答案要自带结构：定义 → 挑几个 → 为什么是这几个 → 分别对应什么。见 `LOGIC.md` §10。
   - **把卷面题面里的每个限定词单独列一行**——那些词是他准备挖的方向。
   - 再加至少 4 条便装问题（听起来不像生化题的）。
   - 每行必须带上要说的那句话，不能只写「见点 04」。
10. **图**：只有「可能让她画」或「可能让她认」的才导（`LOGIC.md` §14）。标明是哪一种，并写出**画的顺序**。
11. **落地**：写 `app/data/<id>.js`，在 `app/index.html` 加一行 `<script src>`。

## 卡数据的字段（照 `app/data/01.js` 抄）

一个卡文件就是一次 `window.CARDS.push({...})`。**所有字段都可省**，省掉的部分对应的
标签页就不出现。HTML 直接写在字符串里，`<b>` 会渲染。

```js
window.CARDS.push({
id:'02',            // 文件名，也是 URL: #/c/02
n:4,                // 题库编号；横向卡不写
merged:[10],        // 并进本题的题号
w:3,                // 权重 3/2/1；横向卡写 0
cross:1,            // 横向卡才写，列表里单独一组
q:'英文题面',
qcn:'中文一句',
sub:'主干说完约 90 秒',

cram:[              // 速背：一页，一点一块，中间留白
 {g:'开口', gn:'这一组是干嘛的'},          // 组标题
 {n:'01', t:'定义',                       // 编号 · 小标签
  big:'一行大字，先给结论',
  en:'“要说的英文原句。”',
  note:'为什么这条要紧',
  warn:'需要警告的（橙色块）',
  good:'顺势能给的第二层（绿色块）',
  fig:{src:'img/x.jpg', cap:'图注'},
  tbl:{head:['列','列'], rows:[['格','格']]}}
],
end:'速背末尾那句话',

sib:[['要点提示','“英文原句。”','为什么要紧']],   // 演练第二屏，十条左右

segs:[             // 演练的四段逐字稿，一段一屏
 {tag:'段 1 · 定义', h:'这一屏在干嘛',
  p:['第一句','第二句'],
  note:'旁注', fig:{src,cap}}
],

why:{              // 演练最后一屏
 rungs:[['为什么…？','因为…']],
 stop:{lbl:'停 · 落在热力学', say:'“停止句。”'}
},

recog:[            // 同一个答案，不同问法
 {q:'他可能这样问？',
  mean:'他要的其实是哪一层',
  say:'“直接给要说的那句话。”',     // 必填，不能只写「见点 04」
  tail:'补充',
  odd:1}                            // 1 = 便装问题，橙色底
],

figs:[             // 只收可能让她画 / 让她认的
 {k:'画',          // '画' 或 '认'
  src:'img/x.jpg', t:'标题', cap:'说明', src2:'出处'}
],

ask:[              // 追问，按组
 {g:'定义类', gn:'这一组的性质', items:[
  {r:'实测',       // 实测 / 高 / 中
   q:'英文问题？',
   en:'“八分答案，说完就停。”',
   cn:'被逼问才给的第二层',
   warn:'书里没有 / 待核',
   good:'加分的说法',
   fig:{src,cap}}
 ]}
]
});
```

**加一张卡的两步**：写 `app/data/<id>.js`，在 `app/index.html` 的 script 区加一行
`<script src="data/<id>.js"></script>`。列表页会自动把它从「未写」挪到「已写」。
